# LAD Site

The project website for **LAD (Log Anomaly Detector)**, a Python-based pipeline for log monitoring and semantic anomaly detection using Fluentd, Qdrant, and Google Gemini.

## Website

Once GitHub Pages is enabled, the site will be available at:

https://cranish07.github.io/lad-site/

## Publish with GitHub Pages

In the repository settings, open **Pages** and set the source to:

- **Deploy from a branch**
- Branch: `main`
- Folder: `/ (root)`

The site is served from `index.html`. Its architecture images are loaded from the `CrAnish07/LAD` repository.
